# Day 32 - NumPy Array Creation Methods

## 📖 Overview

Today I learned different methods of creating NumPy arrays. I explored functions for creating arrays with default values, generating sequences, reshaping arrays, and creating identity matrices.

---

## 📚 Topics Covered

- `np.zeros()`
- `np.ones()`
- `np.full()`
- `np.arange()`
- `np.linspace()`
- `np.reshape()`
- `np.eye()`

---

## 🛠 Programs Practiced

### 1. Creating Arrays with Zeros
- Created 1D and 2D arrays using `np.zeros()`.
- Learned that NumPy creates floating-point zeros by default.

### 2. Creating Arrays with Ones
- Created 1D and 2D arrays using `np.ones()`.

### 3. Creating Arrays with a Specific Value
- Used `np.full()` to create arrays filled with a custom value.

### 4. Generating Sequences
- Used `np.arange()` to generate sequences with start, stop, and step values.
- Compared `np.arange()` with Python's `range()`.

### 5. Evenly Spaced Values
- Used `np.linspace()` to generate a specified number of evenly spaced values between two numbers.
- Learned that `linspace()` includes the end value.

### 6. Reshaping Arrays
- Converted a 1D array into a 2D array using `reshape()`.
- Learned that the total number of elements must remain the same after reshaping.

### 7. Identity Matrix
- Created identity matrices using `np.eye()`.

---

## 💡 Key Learnings

- `np.zeros()` creates arrays filled with zeros.
- `np.ones()` creates arrays filled with ones.
- `np.full()` creates arrays filled with any specified value.
- `np.arange()` generates arrays using start, stop, and step values.
- `np.linspace()` generates evenly spaced values and includes the stop value.
- `reshape()` changes the shape of an array without changing its data.
- `np.eye()` creates an identity matrix.
- Understanding the difference between `np.arange()` and `np.linspace()`.
