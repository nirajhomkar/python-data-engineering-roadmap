# 1️⃣ Reading a CSV File

CSV stands for:

**Comma-Separated Values**

A CSV file stores data in rows and columns.

Example:

```text
Employee_ID,Name,Department,Salary,Experience
101,Amit,IT,50000,2
102,Rahul,HR,75000,4
103,Priya,IT,60000,3
