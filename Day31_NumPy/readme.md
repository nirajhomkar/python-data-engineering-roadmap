## 💡 Key Learnings

- NumPy arrays are different from Python lists.
- Vectorized operations remove the need for explicit loops in many numerical tasks.
- Array indexing uses the format `arr[row, column]`.
- Slicing follows the same start-inclusive, end-exclusive rule as Python lists.
- Array attributes like `shape`, `ndim`, `size`, and `dtype` describe the structure of the data.
