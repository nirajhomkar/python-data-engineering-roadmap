# Day 35 - NumPy Random Module

## 📖 Overview

Today I learned how to generate random data using NumPy. I explored functions for creating random decimal numbers, random integers, randomly selecting values from a list, and making random results reproducible using seeds.

---

## 📚 Topics Covered

- `np.random.rand()`
- `np.random.randint()`
- `np.random.choice()`
- `np.random.seed()`

---

## 🛠 Programs Practiced

### 1. Random Decimal Numbers
- Generated 1D and 2D arrays of random decimal numbers using `np.random.rand()`.

### 2. Random Integers
- Generated random integers within a specified range using `np.random.randint()`.

### 3. Random Selection
- Selected random values from a list using `np.random.choice()`.

### 4. Reproducible Random Numbers
- Used `np.random.seed()` to generate the same random sequence repeatedly.

---

## 💡 Key Learnings

- `np.random.rand()` generates decimal numbers between 0 and 1.
- `np.random.randint()` generates random integers in a specified range.
- `np.random.choice()` randomly selects values from a given list or array.
- `np.random.seed()` makes random number generation reproducible.
- `randint()` excludes the upper bound.
- `choice()` allows repetition by default.
