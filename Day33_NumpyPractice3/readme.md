# Day 33 - NumPy Mathematical Operations

## 📖 Overview

Today I learned NumPy mathematical operations and aggregation functions. I also understood how to perform row-wise and column-wise operations using the `axis` parameter.

---

## 📚 Topics Covered

- `sum()`
- `mean()`
- `min()`
- `max()`
- `std()`
- `var()`
- `axis=0`
- `axis=1`

---

## 🛠 Programs Practiced

### 1. Sum of Array Elements
- Calculated the total of all elements using `sum()`.

### 2. Mean of Array Elements
- Calculated the average value using `mean()`.

### 3. Minimum and Maximum Values
- Found the smallest and largest elements using `min()` and `max()`.

### 4. Standard Deviation
- Calculated the spread of data using `std()`.

### 5. Variance
- Calculated the variance of the dataset using `var()`.

### 6. Column-wise Operations
- Used `axis=0` to perform operations on columns.

### 7. Row-wise Operations
- Used `axis=1` to perform operations on rows.

---

## 💡 Key Learnings

- `sum()` returns the total of all elements.
- `mean()` returns the average value.
- `min()` finds the smallest value.
- `max()` finds the largest value.
- `std()` measures how spread out the data is.
- `var()` measures the variance of the dataset.
- `axis=0` performs operations column-wise.
- `axis=1` performs operations row-wise.
